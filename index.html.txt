專案規格書：今天吃什麼？美食決策器
一、專案概述
1.	專案名稱：今天吃什麼？美食決策器
2.	解決痛點：解決現代人用餐時的選擇困難症，並避免「抽中店家後發現已打烊」或「抽中後還要手動開搜尋引擎尋找位置」的麻煩。
3.	專案目標：提供一個開啟即用、具備豐富視覺效果、能自動比對目前營業時間，並能一鍵開啟地圖導航的互動式網頁應用程式。
二、目標使用者與使用情境
1.	目標使用者：面臨選擇困難症的學生、上班族以及宵夜族群。
2.	使用情境：
o	聚餐決策：多人在選擇餐點時，點擊「幫我決定」按鈕，透過轉盤動畫與禮花效果增加決策趣味性。
o	宵夜過濾：深夜想找食物時，開啟自動過濾功能，網頁會自動排除白天限定的便當店，僅針對目前正在營業的宵夜店家進行抽選。
o	一鍵導航：抽選出決定結果後，直接點擊網頁上的地圖按鈕，跳轉至地圖服務觀看店家評價與導航路線。 
三、系統架構與技術說明
1.	前端頁面：採用單一網頁檔案架構，整合頁面架構、樣式設計與腳本邏輯，方便部署與載入。 
2.	視覺樣式與美化：採用響應式網頁設計，確保在手機、平板與電腦螢幕上皆能自動調整至最佳版面。
3.	圖示與特效：結合圖示庫強化介面引導，並加入禮花粒子動畫套件，在抽出結果時提供歡慶效果。
4.	資料持久化儲存：採用瀏覽器在地儲存記憶體，使用者自訂的菜單與歷史抽取紀錄在重新整理或關閉頁面後不會遺失。
5.	地圖連結整合：動態將抽中的店家名稱進行編碼，自動生成對應的地圖搜尋連結。 
四、詳細功能規格說明
1.	互動式隨機抽籤功能：
o	點擊按鈕後觸發 1.6 秒的快速變換動畫，模擬幸運輪盤轉動的緊張感。
o	確定抽中項目後，自動觸發全螢幕慶祝禮花動畫。
o	卡片上會同步標示該店家的餐點類別、預算等級以及「營業中」或「休息中」的動態標籤。
2.	雙重條件篩選功能：
o	餐點類別篩選：提供正餐主食、街頭小吃、漢堡速食、夜市宵夜等選項。
o	預算範圍篩選：提供百元有找、平價美味、大餐享受等預算區間。
3.	智慧營業時間過濾功能：
o	實時時間抓取：自動讀取使用者當前的電腦或手機系統時間。
o	跨夜營業判定：內建時間演算邏輯，能正確判斷一般營業時間與跨夜營業時間。
o	自動剔除開關：開啟過濾開關後，系統在抽籤前會自動過濾掉目前非營業時間的店家。
4.	地圖導航連結功能：
o	當抽籤結束後，自動於結果區顯示地圖查看按鈕。 
o	點擊後可於新分頁開啟地圖，直接定位該店家並查看評價與路線。 
5.	自訂菜單管理功能：
o	新增功能：使用者可自由輸入店家名稱、餐點類別以及設定該店家的營業起訖時間。
o	列表讀取：即時顯示目前所有自訂店家，並透過彩色燈號標示該店家當下是否正在營業。
o	刪除功能：提供刪除按鈕，可隨時移除不喜歡或已停業的店家。
6.	歷史紀錄功能：
o	自動紀錄：每次抽籤成功後，自動紀錄店家名稱與抽中的時間點。
o	數量限制與清理：預設保存最近 10 次的歷史資料，並提供一鍵清空紀錄的功能。
五、規格與實作內容對應說明
1.	抽籤動畫與特效規格：透過按鈕點擊觸發定時器進行名稱輪播，選定後呼叫禮花動畫函式實作。
2.	雙重條件篩選規格：透過下拉選單綁定事件，在抽選前過濾陣列資料實作。
3.	營業時間判定規格：透過時間物件計算當前總分鐘數，比對店家的營業起訖時間實作。
4.	地圖導航規格：於抽中結果時，動態更新超連結元件的目標網址實作。 
5.	自訂菜單管理規格：透過陣列操作結合瀏覽器在地儲存寫入與讀取實作。
6.	歷史紀錄規格：於抽選完成點呼叫紀錄寫入函式，並限定陣列長度不超過 10 筆實作。
六、人工智慧協作與反覆調整歷程
1.	第一階段：與人工智慧討論產品想法，確定以「今天吃什麼」為主題，並整理出第一版基礎功能規格。 
2.	第二階段：要求人工智慧將純文字介面升級為響應式排版，並導入轉動動畫與抽出結果時的慶祝禮花特效。
3.	第三階段：新增在地儲存機制，解決重新整理後資料遺失問題，並擴充歷史抽取紀錄頁籤。
4.	第四階段：針對「抽中店家卻已經打烊」的實際痛點，要求人工智慧加入營業時間判定邏輯、自動過濾開關，以及地圖快速導航按鈕，完成最終作品。

        // 判斷目前時間是否在營業時間內（支援跨夜，例如 18:00 到 02:00）
        function checkIsOpenNow(openStr, closeStr) {
            if (!openStr || !closeStr) return true;

            const now = new Date();
            const currentMin = now.getHours() * 60 + now.getMinutes();

            const [openH, openM] = openStr.split(':').map(Number);
            const [closeH, closeM] = closeStr.split(':').map(Number);

            const openMin = openH * 60 + openM;
            const closeMin = closeH * 60 + closeM;

            if (closeMin < openMin) {
                // 跨夜營業判斷
                return currentMin >= openMin || currentMin <= closeMin;
            } else {
                // 一般日間營業判斷
                return currentMin >= openMin && currentMin <= closeMin;
            }
        }

        // 隨機抽籤邏輯
        function spinFood() {
            if (isSpinning) return;

            const catFilter = document.getElementById('category-filter').value;
            const budgetFilter = document.getElementById('budget-filter').value;
            const openOnly = document.getElementById('open-only-toggle').checked;

            // 綜合條件過濾
            let candidates = foods.filter(item => {
                const matchCat = catFilter === 'all' || item.cat === catFilter;
                const matchBudget = budgetFilter === 'all' || item.budget === budgetFilter;
                const isOpen = checkIsOpenNow(item.open, item.close);
                const matchOpen = !openOnly || isOpen;
                return matchCat && matchBudget && matchOpen;
            });

            if (candidates.length === 0) {
                alert('目前設定條件下（或此時間點）沒有正在營業的店家，請放寬篩選條件！');
                return;
            }

            isSpinning = true;
            const btn = document.getElementById('spin-btn');
            const displayCard = document.getElementById('display-card');
            const resultText = document.getElementById('food-result');
            const resultIcon = document.getElementById('food-icon');
            const resultTag = document.getElementById('food-tag');
            const resultStatus = document.getElementById('food-status');
            const gmapBtn = document.getElementById('gmap-btn');

            btn.disabled = true;
            gmapBtn.classList.add('hidden');
            displayCard.classList.add('animate-bounce-custom');

            let counter = 0;
            const totalSteps = 20;
            const interval = setInterval(() => {
                const randomTemp = candidates[Math.floor(Math.random() * candidates.length)];
                resultText.innerText = randomTemp.name;
                resultIcon.innerText = randomTemp.icon || "🎲";
                counter++;

                if (counter >= totalSteps) {
                    clearInterval(interval);
                    isSpinning = false;
                    btn.disabled = false;
                    displayCard.classList.remove('animate-bounce-custom');

                    // 確定抽中店家
                    const winner = candidates[Math.floor(Math.random() * candidates.length)];
                    const isOpen = checkIsOpenNow(winner.open, winner.close);

                    resultText.innerText = winner.name;
                    resultIcon.innerText = winner.icon || "🍱";
                    resultTag.innerText = `${winner.cat} • ${winner.budget || '平價'}`;
                    resultTag.classList.remove('hidden');

                    // 顯示營業狀態標籤
                    resultStatus.classList.remove('hidden');
                    if (isOpen) {
                        resultStatus.innerText = "🟢 營業中";
                        resultStatus.className = "text-xs px-2 py-0.5 rounded-full bg-emerald-100 text-emerald-700 font-bold";
                    } else {
                        resultStatus.innerText = "🔴 已休息";
                        resultStatus.className = "text-xs px-2 py-0.5 rounded-full bg-rose-100 text-rose-700 font-bold";
                    }

                    // 設定 Google 地圖連結
                    gmapBtn.href = `https://www.google.com/maps/search/?api=1&query=${encodeURIComponent(winner.name)}`;
                    gmapBtn.classList.remove('hidden');

                    // 呼叫禮花特效
                    confetti({ particleCount: 80, spread: 60, origin: { y: 0.6 } });

                    // 寫入歷史紀錄
                    addHistory(winner.name);
                }
            }, 80);
        }

        // 渲染店家與營業時間列表
        function renderFoodList() {
            const listEl = document.getElementById('food-list');
            listEl.innerHTML = '';
            foods.forEach((item, index) => {
                const isOpen = checkIsOpenNow(item.open, item.close);
                const li = document.createElement('li');
                li.className = 'flex justify-between items-center text-xs p-2.5 bg-gray-50 rounded-xl hover:bg-orange-50 transition border border-gray-100';
                li.innerHTML = `
                    <div class="flex flex-col">

                        <span class="text-[11px] text-gray-500 mt-0.5">
                            ⏰ 營業時間: ${item.open || '10:00'} - ${item.close || '22:00'}
                            ${isOpen ? '<span class="text-emerald-600 font-bold ml-1">● 營業中</span>' : '<span class="text-rose-500 ml-1">● 休息中</span>'}
                        </span>
                    </div>
                    <button onclick="deleteFood(${index})" class="text-gray-300 hover:text-red-500 p-1.5 transition"><i class="fa-solid fa-trash-can"></i></button>
                `;
                listEl.appendChild(li);
            });
            localStorage.setItem('my_foods_v2', JSON.stringify(foods));
        }

        // 新增店家
        function addFood(e) {
            e.preventDefault();
            const nameInput = document.getElementById('new-food-name');
            const cat = document.getElementById('new-food-cat').value;
            const open = document.getElementById('new-food-open').value;
            const close = document.getElementById('new-food-close').value;
            const name = nameInput.value.trim();

            if (!name) return;

            foods.push({ name, cat, budget: "$$", icon: "🍱", open, close });
            nameInput.value = '';
            renderFoodList();
        }

        // 刪除店家
        function deleteFood(index) {
            foods.splice(index, 1);
            renderFoodList();
        }

        // 新增歷史紀錄
        function addHistory(name) {
            const time = new Date().toLocaleTimeString([], { hour: '2-digit', minute: '2-digit' });
            history.unshift({ name, time });
            if (history.length > 10) history.pop();
            localStorage.setItem('food_history_v2', JSON.stringify(history));
            renderHistory();
        }

        // 渲染歷史紀錄
        function renderHistory() {
            const listEl = document.getElementById('history-list');
            listEl.innerHTML = '';
            if (history.length === 0) {
                listEl.innerHTML = '<li class="text-xs text-gray-400 text-center py-4">尚無抽取紀錄</li>';
                return;
            }
            history.forEach(item => {
                const li = document.createElement('li');
                li.className = 'text-xs p-2 bg-gray-50 rounded-lg flex justify-between text-gray-600';
                li.innerHTML = `<span>🎉 抽中了 <strong>${item.name}</strong></span><span class="text-gray-400">${item.time}</span>`;
                listEl.appendChild(li);
            });
        }

        // 清空歷史紀錄
        function clearHistory() {
            history = [];
            localStorage.removeItem('food_history_v2');
            renderHistory();
        }

        // 切換面板
        function switchTab(tab) {
            const customPanel = document.getElementById('panel-custom');
            const historyPanel = document.getElementById('panel-history');
            const customTabBtn = document.getElementById('tab-custom');
            const historyTabBtn = document.getElementById('tab-history');

            if (tab === 'custom') {
                customPanel.classList.remove('hidden');
                historyPanel.classList.add('hidden');
                customTabBtn.className = "flex-1 py-2 text-center font-bold text-orange-600 border-b-2 border-orange-500 text-sm";
                historyTabBtn.className = "flex-1 py-2 text-center font-bold text-gray-400 border-b-2 border-transparent text-sm";
            } else {
                customPanel.classList.add('hidden');
                historyPanel.classList.remove('hidden');
                historyTabBtn.className = "flex-1 py-2 text-center font-bold text-orange-600 border-b-2 border-orange-500 text-sm";
                customTabBtn.className = "flex-1 py-2 text-center font-bold text-gray-400 border-b-2 border-transparent text-sm";
            }
        }
